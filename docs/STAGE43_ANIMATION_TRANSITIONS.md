## Confirmed native evidence

`1409bd3b0` evaluates the primary instance at component +0x70. Component
+0xaa stores the action index, +0xac the phase index, +0xad a phase repeat
counter. +0xae requests a deferred switch and +0xb8 supplies its delta.
These are runtime fields, not serialized asset offsets.

`1409bcd20` processes the transition instance at component +0x78 while
component byte +1 has bit 2 set. Transition +0x58 bit 1 selects a saved
delta. Duration is `(byte(+0x59) + 1) / 60`; elapsed time is
`u16(+0x5a) / 15360 + delta`. Reaching duration clears the active bit.
Otherwise native code writes elapsed/duration to a downstream field and
stores truncated elapsed*15360 back in the counter. The downstream weight's
direction and bone blend implementation remain unverified.

14173cd70 and 15360 (`00007046`) at 14173cf50. Raw evidence is under
reports/ghidra/raw/stage43-transition-*.json; decompiled functions are under
reports/ghidra/raw/skin-palette-candidates/.
